FORTNITE CHEST COUNTER

QUICK START: Extract the entire FortniteChestCounter.zip into a writable folder.
Open ChestCounter.exe (or Start.cmd), then choose Add replays or Choose folder.
Windows 10/11 x64 with .NET Framework 4.8 is required.
The portable ZIP is already built; Rust, Python and administrator access are not needed.
Keep ChestCounter.exe.config and bin/replay-analyzer.exe beside the app.

If you downloaded source code, install Rust and its Windows C++ build tools once,
then double-click Start.cmd to build and launch. Later runs use the existing build.
For instant use without build tools, download FortniteChestCounter.zip from Releases.
Only the recording player's own opened and broken chests are saved.
Click Open for your personal match details.

Chests per match = your recorded opened + broken total / saved matches.
Enter your total Matches to see the approximate total chests for that match count.
Example: 200 chests / 10 saved matches = 20 per match; enter 15 for 300 total.
Saved matches and chests are not added again.
Possible loot estimates are excluded. Forecasts are approximations.

Clear all data requires typing DELETE. It clears saved history and its backups,
and keeps your original Fortnite replay files.

Existing personal history is preserved; no re-import is needed.
Local data is saved in data/statistics.json and must not be uploaded.
